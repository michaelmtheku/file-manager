# Frontend - File Manager

## Tech Stack
- React + Vite
- Tailwind CSS
- Context-based state for auth & files
- Axios API layer

## Commands
- `npm run dev`
- `npm run build`
- `npm run preview`

## Environment
Set `VITE_API_BASE` to your backend API base (e.g., `http://localhost:5000/api`).

## Future Improvements
